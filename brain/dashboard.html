What it works on

Auto runs

When this is ON, Claude can start bot tests while you are away and read what happened. It can only do two things: reload the game's scripts and run test <names>. No limit on how many or how often. It is OFF every time the brain starts. Turn it OFF to stop a run at once.

Training

Off
When this is on, the bot improves itself with nobody here: it searches for better settings in the simulators, proves the best one in the real game with several bots at once, and keeps it only if it really is better. No limit on time or cycles. It only moves numbers inside safe ranges; it never edits code.
Champion (what differs from the defaults): nothing yet

3. The arena

          

          

          
Built high above you. Spectators are fenced in, the stands are lit, mob griefing is off and mobs do not spawn while it runs, so nothing in it can be destroyed. You are put in the top row (creative) and back where you were after.

        

      

    


    

      

        

          
Train the bots

          
One bot fights mobs, bout after bout. Every pair of bouts is the same fight played twice: with the best doctrine so far and with a slightly changed one. The change has to win over several pairs to take over. About 25-40 pairs an hour. Nothing is spent but time.
